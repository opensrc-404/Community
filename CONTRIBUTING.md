# Contributing to OpenSRC 404 🚀

Welcome to OpenSRC 404! We're excited to have you contribute.

## How to Contribute

1. Fork this repository.
2. Clone your fork.
3. Create a new branch for your changes.
4. Make your changes.
5. Commit and push to your fork.
6. Open a Pull Request against the `main` branch.

## Pull Request Guidelines

- Never push directly to the main branch.
- Keep your changes focused and meaningful.
- Provide a clear PR description.
- Ensure all CI checks pass.
- Wait for maintainer review and approval.

## Code of Conduct

Be respectful, inclusive, and supportive of other contributors.

**Happy contributing! 💜**
